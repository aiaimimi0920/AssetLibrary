# 历史归档目录规则

本目录是旧 AssetLibrary 的静态历史参考，不是当前源码根或开发入口。

当前项目以父目录的 `AGENTS.md`、`DEVELOPMENT_PLAN.md` 和 `docs/DEVELOPMENT_STANDARD.md` 为准。旧规则原文保存为 `AGENTS.legacy.md`，仅供追溯，不得作为当前指令。

- 默认只读；只为当前任务查阅相关历史文件，不进行全目录开发或重构。
- 不在本目录增加新功能，不运行旧 Cargo/Web 测试、Docker/基础设施部署、Wrangler 或历史发布流程。
- 旧 ADR、计划和验收报告不约束新架构，不证明新实现完成。
- 不输出 `.env`、密钥、凭据、缓存或旧运行产物中的秘密信息。
- 新项目检查、依赖发现和发布排除本目录；秘密保护不因此关闭。
- 如明确需要修正归档说明或恢复文件，先确认授权与路径，不覆盖新工作，不删除历史文件。

归档范围、特殊路径映射和校验结果见 `ARCHIVE.md`。
