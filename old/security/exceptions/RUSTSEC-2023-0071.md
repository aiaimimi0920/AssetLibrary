# RUSTSEC-2023-0071 lock-only exception

- Created: 2026-09-03
- Expires: 2026-12-02
- Owner role: `assetlibrary-api-owner`
- Reviewer role: `assetlibrary-security-reviewer`
- Affected lock entry: `rsa 0.9.10`

`jsonwebtoken 11` declares `rsa` as an optional dependency of its
`rust_crypto` backend. AssetLibrary enables only `aws_lc_rs`; the reachable JWT
verification implementation is AWS-LC. Cargo still records the disabled
optional package in `Cargo.lock`, and `cargo audit` scans lock entries without
feature reachability.

Evidence:

```powershell
cargo tree --target all -i rsa@0.9.10
# warning: nothing to print
```

Do not extend this exception merely because it exists. Before expiry, check
whether `jsonwebtoken` has stopped retaining the disabled backend or whether a
feature-aware audit release can distinguish unreachable optional packages.
The role identifiers are policy ownership, not proof that a release review has
occurred; the formal release must retain the protected-branch review evidence.
