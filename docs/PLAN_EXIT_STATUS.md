## 2026-10-06 联合验证（历史）

新增 `tests/web-download-authorization.test.mjs`：使用实际 Web 续传模块、实际分发业务核心及独占 Miniflare D1/R2，生成超过两段的应用 ZIP，真实上传、格式检查、版本和独立审核。AV 为合成事实；只有宿主测试调用假设部署准入的业务核心，生产 HTTP 没有测试开关。

1. 第一段成功后撤销：同次下载的第二个 Range 被当前授权检查拒绝，客户端清空缓存。
2. 第二段运输故障后撤销：客户端保留第一完整段；手动继续申请票据被拒绝，不再取得内容字节，缓存清空。
3. 第二段运输故障后下架：新票据被拒绝，缓存清空，不复活终态。
4. 撤销后再授予：旧票据仍拒绝；从零获取新票据并下载，完整字节与 SHA-256 校验通过。
5. 普通 Worker 的票据 HTTP 在以上假设测试后仍返回 `SCANNER_CLOUD_NOT_VALIDATED`。

聚焦运行：`rtk proxy pnpm test web-download-authorization.test.mjs web-download-resume.test.mjs web-download-range.test.mjs`，10 pass / 0 fail / 0 skip。首次运行因新测试源码占位字符未正确替换而解析失败，修正后通过；不是产品运行故障。已有 .27 浏览器和 CI 证据不冒充本轮新测试通过。生产源码、Schema、依赖、版本号均未改变，无需新运行版本或重复浏览器/云部署。

## 接下来必须具备的条件

- **正式身份（已授权接入）**：NAccount 合同、客户端登记和会话实现已完成并上线；继续真实浏览器登录、私有业务、退出及账号撤销验收。当前 Edge 自动化点击登录出现 ERR_BLOCKED_BY_CLIENT，已请求用户手动核验，不绕过浏览器保护；配置就绪不能代替真实登录。
- **原生安全（用户延期）**：恢复组件/fork 风险和供应链复核，完整覆盖实际二进制，不隐去告警或手写证明补绿；完成新引擎/签名候选的实际切换与回滚验证。
- **网络与资源边界（用户延期）**：恢复 scanner 的资源、出站、底层清理和私有对象无旁路验收；本地假设不能代替。
- **完整云/生产退出**：在上述条件满足且获得对应云操作授权后，将当前同包候选用于真实 Workers/D1/R2 全业务验收，保留失败和恢复记录；不复用旧 scanner 云切片证明新镜像。

这些是剩余条件，不是本轮已执行的操作。总计划仍未完成；不得自动取消用户延期、创建真实账户、切换云镜像或降低 `SCANNER_CLOUD_NOT_VALIDATED` 门禁。
